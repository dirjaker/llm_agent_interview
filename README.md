## 如何使用

### 面试准备
1. 按顺序阅读 01-06，建立完整知识体系
2. 重点准备 04（Agent）、03（RAG）、02（Prompt）— 最高频考点
3. 练习 12（系统设计）和 13（编码题）— 手撕环节

### 日常开发
- 遇到具体问题直接翻对应章节
- 每章末尾有「实战难题」，是生产环境真实踩坑

### 查漏补缺
- 每章开头有「知识图谱」，标注哪些是高频、哪些是加分项
- 每题有难度标记：⭐ 基础 ⭐⭐ 进阶 ⭐⭐⭐ 高级
