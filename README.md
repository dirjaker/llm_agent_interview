## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/llm_agent_interview.git
cd llm_agent_interview

# 创建虚拟环境
conda create -n llm_agent_interview python=3.12 -y
conda activate llm_agent_interview

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
