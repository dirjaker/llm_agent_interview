## 如何使用

### 面试准备（2 周冲刺计划）

**第 1 周：核心知识**
- Day 1-2: 03-LLM基础原理 + 02-大模型发展脉络
- Day 3: 04-Prompt工程
- Day 4-5: 05-RAG系统设计
- Day 6-7: 06-Agent架构与实现 + 07-记忆系统

**第 2 周：进阶 + 冲刺**
- Day 1: 08-多智能体 + 09-MCP
- Day 2: 12-模型微调 + 13-模型部署
- Day 3: 16-安全防护 + 15-评估测试
- Day 4-5: 19-系统设计题
- Day 6-7: 20-算法与编码题

### 日常开发
- 遇到具体问题直接翻对应章节
- 每章末尾有「实战难题」，是生产环境真实踩坑

### 查漏补缺
- 每章开头有「知识图谱」，标注哪些是高频、哪些是加分项
- 每题有难度标记：⭐ 基础 ⭐⭐ 进阶 ⭐⭐⭐ 高级
